# ARMADA

[Official website](https://armada-dn.eu/)

ARMADA is a European doctoral research network developing reliable
Conversational Data Analytics: systems that combine natural-language
interaction with structured data to produce explainable, verifiable, and
efficient answers.

This GitHub organization is where the ARMADA research team shares the
open-source software resulting from the project.

## Research team

The network trains **15 Early Stage Researchers** in Conversational AI,
bringing together expertise in natural language processing, machine learning,
data management, and algorithms. Their work focuses on domain alignment,
grounding, explainability, soundness, interactive correction, and efficient
computation for applications in sensitive domains such as medicine, education,
and business intelligence.

## Partners

ARMADA connects **8 organizations from 7 countries** in an interdisciplinary
network of researchers and scientific partners:

**ARC · AU · CNRS · IBM · KTH · JRC · TU · UGA · UPC · UU · UVR · UZH · ZHAW**
